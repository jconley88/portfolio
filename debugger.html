Trace-Based Debugging Tool

An always-on debugger designed to accelerate active development; offering more than just flaw detection.

Update: A beta version is now released! You can now view Code Beacon on the VS Code Marketplace.

This project has been a long-term ambition of mine, and in 2024, I dedicated significant time to developing an alpha version. It builds on the philosophy of a time-traveling debugger to present a comprehensive, navigable map of all execution data. Unlike traditional debuggers that focus on microscopic inspection of a single point in a running program, this tool traces and records details about the entire execution flow. It then filters and aggregates this into higher level views to help you reason about code flow and enable you to quickly target the files, classes and methods you need to work in.

Instead of tediously scattering individual debug or print statements around to piece together the execution path and data flows, wrap your entire application in this tracer, run your code and you're done. VS Code will now show:

  • a simple compressed call graph showing your class and method interactions
  • an exploded single-file view of all executed methods in chronological order
  • a filtered view of the file explorer acting as a tab management proxy and helping you to navigate to just the files you're currently working on
  • a raw stack trace scoped to just your applications code so you don't have to wade through 90% library calls
This approach not only speeds up each execute-inspect-modify cycle but also reduces the number of cycles needed to build a mental model and produce a solution.

The Ruby pilot has been released with more languages to come! I am eager to share more details about this project and welcome any inquiries or feedback.
