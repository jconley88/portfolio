LeapStories

A browser extension that catches the Hacker News stories you miss when rankings shift between page loads.

LeapStories is available on the Chrome Web Store.

Pagination for ranking sites, like YC Hacker News, poses an interesting problem. Have you ever noticed how, on page 2 of a ranked news site, some of the stories are sometimes repeats from page 1? If you go back to page 1, you'll see a new story or two that you would have missed. These are the LeapStories that the name of this extension refers to.

Point in time queries or live polling could theoretically address this "issue", but they're heavy handed and come with trade-offs. We don't truly need either, we just want to capture all new stories at the point of page load even if they're now technically on the prior page. I wrote this extension not just to solve this particular problem, but also as concrete suggestion that it should (and can be) solved.

While this is a relatively light client side solution requiring only an additional single api call, it could also be solved server side without full point-in-time snapshotting.

Key Features
  • Leap story detection and injection
  • Duplicate story dimming
  • Unobtrusive reuse of existing styling
  • Privacy-first, no tracking
  • Also available for Firefox
Technologies
  • JavaScript
  • Chrome Extension (Manifest V3)
  • Chrome Storage API: session & local
